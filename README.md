# Astrea
![Alt text](https://i.postimg.cc/3J9YjChc/Recording-2026-08-16-200039.gif)

## Inspiration
Wellness is an essential part of ones mental health. Yet because of loneliness, work, and stress people often neglect their overall wellness. Our memories are deeply intertwined with our wellness: the good, the bad, and the in between. Their memories are scattered, making it difficult to reflect on the journey of life and what makes it beautiful. This is why we built Astraea, it connects state of mind → with lived experiences → to memory constellations. 

We found out that Emotional Journaling helps regulate emotions and benefits mental health. Our primary themes are to store everyday moments of happiness to help self-reflect.
_________________________________________________________
## What it does

Astrea is a smart mood journal with:

⤷**Stars**: This feature lets user store memories in the form of stars. They can write about their experiences and self reflect. Along with this they can include: photos, audio, video. User has the ability to choose and stack favourite memories.

⤷**Constellations**: User can join their favourite memories to form constellations! Constellations can be associated by a feeling or a place. The user can overlook previous stars & constellations to help feel better or know their progress!

⤷**Brighter Day**: This is a make tomorrow better feature. Where based on past experiences, and association of tasks & schedules the user gets recommendation of how to make the next day better!

_________________________________________________________

## How we build it

We built it with html, flask, css and a SQLite database. Before starting the code, we wanted to ensure we had a clear vision of what we wanted to build, so we created a mockup in Figma.

After finalizing the mockup, we began developing a simple Flask app without any design and then integrated the design into the workflow.

We managed the project using GitHub Issues, dividing the work into tasks, which was essential for staying organized during a time-constrained hackathon.

## How to run it

You need to install python and flask if you want to run it locally.

With : `pip install flask`

And to start the app locally :

`python app.py`

or

`flask run`
